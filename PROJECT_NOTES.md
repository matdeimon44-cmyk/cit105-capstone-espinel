# Project Notes

## Project Organization
The project will be organized into small Python files based on responsibility. The Streamlit interface will be kept separate from data handling and AI-related functions when possible.

## File Conventions
- Python files use lowercase names.
- Related functions should stay together.
- Files should have clear and descriptive names.
- Credentials and API keys must never be stored directly in the repository.

## Code Style
- Follow standard Python naming conventions.
- Use descriptive variable and function names.
- Keep functions small and focused on one task.
- Add comments only when they help explain code that is not obvious.
- Avoid unnecessary duplicate code.

## AI Assistant Guidelines
The AI assistant may help explain code, suggest solutions, identify errors, and improve documentation. The assistant should not change the purpose or scope of the project without approval.

AI-generated code must be reviewed and tested before it is added to the final application.

The assistant must never place passwords, API keys, tokens, or other credentials directly in source code or repository files.

## Project Scope
The application is a Baseball Training Tracker built with Streamlit. Development should remain focused on the approved user stories and avoid adding unnecessary features that increase the scope of the capstone.
