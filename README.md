# Baseball Training Tracker

A simple Streamlit application that helps baseball players record, organize, and review their training sessions.

## Project Status

Capstone proposal and repository scaffold in progress.

## Planned Features

- Add baseball training sessions
- View previous training sessions
- Filter sessions by training type
- View training-time summaries
- Generate an AI training suggestion based on recent sessions

## Technology

- Python
- Streamlit
- Generative AI
